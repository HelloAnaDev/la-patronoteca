Comparte tu patrón

No hace falta registrarse. Tu patrón se revisará antes de publicarse: analizamos el archivo por seguridad y comprobamos que el contenido sea adecuado para la comunidad.

Sobre tu email: no lo mostramos nunca en la web ni lo usamos para enviarte publicidad — de hecho, La Patronoteca no gestiona publicidad de ningún tipo, así que tu email nunca se usará con ese fin. Solo sirve para avisarte de si tu patrón se ha aceptado, y como medida de seguridad frente a envíos abusivos.
Solamente se utilizará para avisarte cuando se haya subido este patrón y para seguridad de la comunidad.
Si sabes de dónde sale este patrón, indícalo aquí (el enlace o el nombre de quien lo creó) para darle crédito.
Puede ser uno o varios archivos: PDF, fotos de las hojas del patrón, o ambos.
Ten en cuenta que una persona que quiera descargar un patrón querrá ver cómo queda el producto antes de invertir material y tiempo en hacerlo. Te recomendamos usar una foto del producto final para la portada.
Mantén pulsada una foto y arrástrala para cambiar su orden, o escribe el número debajo de cada una.
¿No encuentras tu técnica? Escríbela y pulsa coma o Enter para añadirla (máximo 1). La revisaremos antes de que aparezca para todos.
¿No encuentras la categoría de tu patrón? Escribe qué etiquetas pondrías y pulsa coma o Enter tras cada una para añadirla (verás un recuadro con una X para borrarla si te equivocas). Por ejemplo, si es una camisa de mujer, escribe camisa, pulsa coma, escribe mujer, pulsa coma. Usa palabras generales, fáciles y descriptivas. Máximo 3 etiquetas.
